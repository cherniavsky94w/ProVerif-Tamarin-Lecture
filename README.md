# Формальна верифікація криптографічних протоколів: ProVerif і Tamarin

Навчальний модуль з однієї лекції та двох практичних робіт. Студенти вчаться описувати протокол формальною моделлю, формулювати властивості секретності й автентифікації, запускати ProVerif і Tamarin, читати знайдену трасу атаки та пояснювати, що в протоколі пішло не так. Практичні роботи побудовано на відомих протоколах вебавтентифікації (JWT, OAuth 2.0), у моделі яких навмисно внесено поширені в реальних системах вади.


## Результати навчання

Після модуля студент уміє:

1. пояснити символьну модель криптографії та модель активного зловмисника Долєва–Яо;
2. сформулювати властивість секретності та автентифікації (у формі кореспонденції подій) і відрізнити ін'єктивну автентифікацію від неін'єктивної;
3. установити ProVerif і Tamarin, запустити перевірку моделі та прочитати результат;
4. за трасою атаки відтворити атаку у вигляді діаграми обміну повідомленнями й співвіднести її з відомим класом вразливостей;
5. виправити модель, повторно перевірити її та переконатися, що доведення не є вакуумним (перевірка досяжності).

## Варіанти

Кожна практична робота має 6 варіантів. Номер варіанта: `((номер у списку групи − 1) mod 6) + 1`. Файли варіантів:

- ПР1: `lab1-proverif-jwt/models/jwt_v<N>.pv`
- ПР2: `lab2-tamarin-oauth/models/oauth_v<N>.spthy`

Розминкові моделі (протокол Нідгема–Шредера з відкритим ключем) спільні для всіх і лежать у теках `warmup/`.

## Для викладача

Ключ відповідей, еталонні (виправлені) моделі, генератор варіантів і скрипт автоматичної перевірки всіх моделей лежать у зашифрованому архіві `instructor-solutions.7z` (7-Zip, AES-256, назви файлів теж зашифровано). Пароль викладачам надає автор курсу.

Розпакуйте архів у корені репозиторію й перевірте, що всі моделі дають очікувані результати:

```bash
7z x instructor-solutions.7z    # macOS (brew install sevenzip): 7zz x …; Windows: 7-Zip
bash instructor/check_all.sh
```

Розпакована тека `instructor/` внесена в `.gitignore`. Не публікуйте її і не передавайте студентам.

Усі моделі перевірено на ProVerif 2.05 і Tamarin 1.12.0 (Maude 3.5.1). Кожна модель ПР1 перевіряється менш ніж за секунду, кожна модель ПР2 за 7–12 с на ноутбуці.
